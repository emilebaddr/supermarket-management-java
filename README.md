# supermarket-management-java
Supermarket Management System

A Java-based supermarket management system developed and refined as an academic project.

The system provides an interactive menu for managing and monitoring various supermarket operations, including products, customers, orders, cashiers, profits, and reports.
Features

- Product and inventory management
- Customer and employee management
- Sales and transaction management
- Object-oriented programming
- Inheritance and polymorphism
- Interfaces
- Arrays and ArrayLists
- CSV file handling
- UML design

Technologies

- Java
- Object-Oriented Programming (OOP)
- UML
- CSV File Handling
